## الثغرات المعروفة

**UNVERIFIED.** لم يُشغَّل `npm audit` و`npm outdated` لأنهما يتصلان بالسجل الخارجي، وهذا خارج التفويض. ولا توجد قاعدة ثغرات محلية. فلا أستطيع القول إن الحزم سليمة أو غير سليمة.

**لتشغيله بأمان على جهاز المطور.** لا يغيّر الأمر الأول والثاني شيئًا:

```bash
npm audit --omit=dev
```

```bash
npm outdated
```

## مكتبات داخلية تحل محل حزم

المشروع قلّص الاعتماديات بكتابة ما يلي داخليًا: PDF وXLSX وDOCX وZIP وDER/CMS وQR وعميل Redis ومحلل SQL وWeb Push. هذا يقلل مخاطر سلسلة التوريد، لكنه ينقل المسؤولية إلى المشروع.

| المكوّن | الملف | الخطورة إن أخطأ |
|---|---|---|
| التوقيع وCMS | `services/pki.js`، `lib/der.js` | عالية، لأن الوثائق تعتمد عليه |
| قراءة الملفات المرفوعة | `lib/xlsx.js`، `lib/zip.js`، `lib/pptx.js` | متوسطة، فهي تعالج مدخلات خارجية |
| محلل SQL للاستيراد | `lib/sqlparse.js` | متوسطة، وهو يحلل ولا ينفذ حسب ما رُوجع |
| Web Push | `services/push.js` | منخفضة |

## حزم غير ضرورية
