# 02. جرد التقنيات

**مؤكد** يعني وجود دليل في الكود. **UNKNOWN** يعني تعذر التحقق من الملفات المتاحة.

## اللغات

| اللغة | الدور | الحجم التقريبي | الحالة |
|---|---|---|---|
| JavaScript (ES Modules) | الخادم والمتصفح والاختبارات والسكربتات | 230 ملفًا، نحو 51,750 سطرًا | مؤكد |
| SQL | 52 ترحيلًا مع استعلامات مضمنة | 2,700 سطر في الترحيلات | مؤكد |
| HTML / CSS | الواجهة | `index.html` و5 ملفات CSS | مؤكد |
| Shell | تشغيل الحاوية | `docker-entrypoint.sh` | مؤكد |
| Python | أداة مساعدة واحدة، `tools/make-templates.py` | ملف واحد | مؤكد، وخارج مسار التشغيل |

**غير مستخدمة:** TypeScript وPHP وJava وC# وGo. لا توجد ملفات لها ولا بيانات حزم.

## الواجهة الأمامية

| التقنية | الحالة | التفاصيل |
|---|---|---|
| JavaScript بلا إطار عمل | مؤكد | كائن عام `window.UA`، وقوالب نصية مع `innerHTML` |
| React وNext.js وAngular وVue وSvelte | غير مستخدمة | تطبيق React القديم في جذر المستودع حُذف سابقًا |
| إدارة الحالة | مخصصة | الكائن `UA.S`، مع `UA.render()` |
| التوجيه | مخصص | `UA.go(view)` وخريطة `UA.views` و`UA.loaders` |
| جلب البيانات | مخصص | `api()` في `public/app.js` فوق `fetch` |
| مكتبة واجهة | لا يوجد | CSS مكتوب يدويًا، و`style.css` نحو 150 كيلوبايت |
| PWA | مؤكد | `public/sw.js` و`manifest.webmanifest` و`push.js` |
| تعدد اللغات | مؤكد | `i18n.js`، و`i18n_en.js` نحو 432 كيلوبايت يُحمَّل للإنجليزية فقط |

## الخادم

| التقنية | الحالة | التفاصيل |
|---|---|---|
| Node.js | مؤكد | `engines: >=22.5`، وصورة `node:22-alpine`، والبيئة المحلية 24 |
| إطار خادم | لا يوجد | موجّه مخصص فوق `node:http` في `server/http.js` |
| Express وNestJS وDjango وLaravel وغيرها | غير مستخدمة | لا دليل عليها |
| خيوط العمل | مؤكد | `db_worker.js` للاستعلام، و`heavy_worker.js` حتى خيطين للعمليات الثقيلة |
| توليد PDF وXLSX وDOCX وQR وZIP وCMS | مكتوبة داخليًا | `server/lib/` و`server/qr.js` و`services/pki.js`، بلا مكتبات خارجية |

## قاعدة البيانات

| التقنية | الحالة | التفاصيل |
|---|---|---|
| PostgreSQL | مؤكد | المحرك الوحيد المدعوم. محليًا 17.11، وإصدار الإنتاج **UNKNOWN** |
| برنامج التشغيل | مؤكد | `pg` 8.23.1 |
| ORM | لا يوجد | SQL خام عبر محوّل مخصص يحاكي واجهة SQLite المتزامنة |
| Prisma وSequelize وTypeORM وDrizzle | غير مستخدمة | لا دليل عليها |
| SQLite | غير مستخدم | لكن صياغته ما زالت في الترحيلات والكود وتُترجم وقت التشغيل، وREADME يدّعيه خطأً |
| Redis | اختياري | عميل RESP مخصص في `server/cache.js:85` عند ضبط `REDIS_URL`. غير مضبوط في المتغيرات التي عرضها المالك |

## التطوير والنشر

| الأداة | الحالة |
|---|---|
| Git | مؤكد، بلا مستودع بعيد في النسخة المحلية |
| GitHub | حسب إفادة المالك |
