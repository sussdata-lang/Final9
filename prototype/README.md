# نموذج أولي لواجهة الموظفين

نموذج مستقل لمعاينة الشكل والحركة، ولا يمس الموقع: لا يتصل بالخادم ولا بقاعدة البيانات، وكل الأسماء والأرقام فيه توضيحية، وما تدخله يختفي عند تحديث الصفحة.

## التشغيل

```bash
node E:\Cache\static-proto.mjs
```

ثم افتح `http://127.0.0.1:3200/prototype/index.html`.

## الملفات

- `catalog.js`: الأقسام والتبويبات بأسمائها في الموقع، وأعمدة كل جدول وحقول كل نموذج.
- `prototype.js`: التنقل والقوالب والنوافذ والبحث الشامل.
- `prototype.css`: الألوان والخطوط من `uni-erp/public/style.css`، والهيكل مأخوذ من ملف Figma بخطوط أكبر.

الخط والشعار يُقرآن من `uni-erp/public`، فلا تنقل المجلد وحده خارج المشروع.

## اختصارات

- `Ctrl K`: البحث الشامل.
- `Ctrl B`: طي القائمة الجانبية.
