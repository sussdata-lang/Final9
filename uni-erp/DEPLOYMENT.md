# نشر النظام

النظام خادم Node.js مع قاعدة PostgreSQL، ويُضبط بمتغيرات البيئة فقط. فيعمل على Railway أو أي استضافة تشغّل Docker أو على خادم داخلي، بالخطوات نفسها.

## طرق التشغيل

**Docker على أي خادم** (من مجلد المستودع):

```bash
docker build -t suss -f uni-erp/Dockerfile.railway uni-erp
```

```bash
docker run -d --name suss -p 3000:3000 -v suss-data:/app/data --env-file suss.env suss
```

**Node مباشرة على خادم داخلي** (Node 22 أو أحدث، من مجلد `uni-erp`):

```bash
npm ci --omit=dev
```

```bash
node scripts/start-cloud.js
```

وعندها اضبط بنفسك: `NODE_ENV=production`، و`COOKIE_SECURE=1` إذا كان الموقع على HTTPS، و`TRUST_PROXY=1` إذا كان خلف Nginx أو ما يشبهه.

**Railway**: المسار الحالي للبناء `/uni-erp/Dockerfile.railway`، ويجب أن يكون Root Directory هو `uni-erp`. صورة Docker تضبط `NODE_ENV` و`COOKIE_SECURE` و`TRUST_PROXY` و`HOST`، فلا تحتاج إضافتها.

## المتغيرات

ولّد القيم العشوائية على جهازك، ولا تضعها في الملفات المرفوعة:

```bash
node scripts/gen-secrets.js
```

| المتغير | إلزامي؟ | الغرض |
|---|---|---|
| `DATABASE_URL` | نعم | رابط PostgreSQL |
| `PUBLIC_URL` | نعم | رابط الموقع العام، ويظهر في الوثائق ورموز التحقق |
| `UNIVERSITY_NAME` | لا | اسم الجامعة بالعربية. الاسم بلا حروف عربية يُستبدل بالاسم الافتراضي. ويُقبل `Uni_name` أيضاً |
| `SEED_PASSWORD` | عند أول تشغيل | كلمة مرور الحسابات الأساسية عند إنشائها. بدونها تُولَّد كلمة عشوائية تُطبع في السجل مرة واحدة |
| `BACKUP_PASSPHRASE` | موصى به | تشفير النسخ الاحتياطية. احفظها خارج الخادم: بدونها لا تُستعاد النسخ المشفرة |

## الميزات الاختيارية

| الميزة | ما تحتاجه | الحالة في الكود |
|---|---|---|
| الذكاء الاصطناعي | `GEMINI_API_KEY`، و`GEMINI_MODEL` لتغيير النموذج | بدون المفتاح يعمل بديل داخلي مبني على القواعد. لم يُجرَّب مع مفتاح حقيقي |
| تنبيهات الجوال | موقع على HTTPS فقط | تعمل بلا متغيرات: تُولَّد المفاتيح وتُحفظ في القاعدة عند أول استخدام. ويمكن تثبيتها بـ`VAPID_PUBLIC_KEY` و`VAPID_PRIVATE_KEY` |
| الختم الزمني | `TSA_URL` رابط خدمة ختم RFC 3161 | عند فشل الخدمة تبقى الشهادة موقّعة بوقت محلي، وتُسجَّل حالة الفشل |
| النسخ الخارجي | `BACKUP_PUT_URL` رابط يقبل طلب PUT، و`BACKUP_PUT_AUTH` إن لزم | يُرفع الملف المشفر بعد كل نسخة. يمكن وضع `{name}` داخل الرابط لاسم الملف |
| الدخول الموحد | لم يُبنَ بعد | لا يوجد تنفيذ في الخادم. يلزم تحديد المزوّد (LDAP أو Entra أو Google) وبيانات الاتصال به |

## قبل كل نشر على قاعدة فيها بيانات

1. خذ نسخة احتياطية من قاعدة الإنتاج. الترحيلات تعمل تلقائياً عند التشغيل، ولا تراجع آلياً عنها.
2. الترحيل `041` يحذف الصفوف التجريبية المعروفة من الجداول التي زُرعت فيها.
3. مزامنة الأدوار عند التشغيل تحدّث صلاحيات الأدوار الأساسية ما لم يُغيَّر اسمها.
